# Contributing

Run `npm run check` and `npm test`. Changes to a statistical method should include a reference case, edge cases, and a note about when the method is appropriate. Keep the user-row denominator intact. If a new outcome needs a different observation window, update the data contract and test brief together.

Use original practice examples or data you have permission to share. Keep source code comments focused on choices and tradeoffs that help the next reader understand the implementation.
